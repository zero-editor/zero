Segmented agent ring

The number goes. The ring gets one arc per agent in the round: a lit arc means that agent has finished, and a dim arc with a light running along it means it's still working. When every arc is lit, the ring closes and shows the check, the same as today. With one agent, nothing changes. Finished arcs you've already looked at (by visiting the tab) dim to a solid grey, so bright always means new, and the ring never re-cuts. The ring keeps its 10px size inside the 18px slot, and the ✕ gets its space back.
